## Design Context

### Users

Sadiq uses this personal NixOS configuration daily. Terminal interfaces should optimize keyboard-first coding and AI-agent workflows, with fast access to sessions, panes, layouts, logs, and repository context.

### Brand Personality

Strong, clean, and practical. The interface should feel calm, capable, deliberate, and polished without becoming ornamental or visually loud.

### Aesthetic Direction

Refined utilitarian terminal UI using the existing Catppuccin Mocha palette and JetBrainsMono Nerd Font. Prefer crisp hierarchy, restrained accent color, compact information density, and unmistakable focus state. Avoid crowded status bars, excessive icons, novelty decoration, gradients, glow, and color without meaning.

### Design Principles

1. Show information only when it supports an immediate action or decision.
2. Make the active tab, mode, and session state identifiable at a glance.
3. Optimize common coding and AI-agent actions for direct keyboard access.
4. Use color semantically and preserve strong readable contrast.
5. Keep defaults calm; reveal advanced tools through shortcuts and focused panels.
